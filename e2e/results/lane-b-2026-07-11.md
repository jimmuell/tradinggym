## Findings

### Finding 1 (LRN-03/05 blocker; likely bug — needs triage) — OBSERVED
Foundation graduation cannot be completed through the UI in this run.
- **Observed:** clicking "Complete Lesson" on all 5 modules issued `POST lesson_progress` (HTTP 201 ×5,
  captured in the network log), but `/learning/foundation` still read **"0 of 5 modules complete"**,
  "Take Assessment" stayed **disabled**, and `profiles.tier_state` stayed `foundation`.
- **Code (supporting):** `Foundation.tsx` derives `completedCount` from `localStorage 'completedLessons'`
  (lines 22–53) and references `lesson_progress` **0 times**; `useMarkLessonComplete` upserts the server
  `lesson_progress` table (`useLessonProgress.ts:32–33`). `Take Assessment` is `disabled={!allModulesComplete}`
  (`Foundation.tsx:322`).
- **Inference (labeled as such):** a split completion source — writes go to `lesson_progress`, the gate
  reads `localStorage` — would make Foundation un-graduatable via the current UI. Root cause not fully
  confirmed; flagged for triage. This blocks LRN-03 and LRN-05's Foundation leg.
